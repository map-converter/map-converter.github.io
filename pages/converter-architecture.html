The converter reads every format into one model of the map and writes every format from it. The model holds two things: the biology (entities, reactions, annotation) and its drawing (boxes, arcs and bends, each pointing to what it draws by its id). Readers read and writers write, nothing else. What every format shares in the layout is in one module, what only one target needs (yEd, CellDesigner, Newt) in an adapter next to its writer. SBML with layout is written, drawn as the SBGN-ML file. Reading it on this page, SBML without layout and BioPAX are not written yet (dashed). The format details are on the description page.

How it is built

the model: biology and drawing, apart layout, shared by every format one step a file not written yet

Layout

There is no layout algorithm: no route places nodes. A conversion translates the map: the adapters change sizes, ports, bends and arc ends, never a node's centre. Two exceptions, each listed under the map: the room for a complex's name in CellDesigner (its members move up) and Newt's margin (in the files for Newt only). The advanced CellDesigner file moves a few nodes so that lines meet straight (cd_tidy.py): the main file, for a one-time conversion and for continuing in CellDesigner, though such moves add up a little on every trip between editors. Two fallbacks move none: straight & bends (the same drawing without the moves) and straight line. CellDesigner (as drawn), for going back and forth between editors, moves none either: where CellDesigner would draw a line otherwise than the input map, it gets edit points that CellDesigner draws over or along: two around a process glyph more than 3 px from midway, one under a large node that a level line enters beside its centre, each at least 3 px outside the nodes. A line a few px off level stays so. A multimer is drawn as a dimer, its count above 2 a unit of information, so no node grows. To CellDesigner and back, 5 of 438 nodes move by more than 1 px (at most 3 px), and a second trip moves none.

ModuleWhat it does
layout.pyFor every format: the main reactant and product of each process, the bends that matter (the long L, bends that move a line by more than 20 px), two processes on the same species kept apart, an arc's route without the process ports, the bends of a map read from CellDesigner aligned where they lie within 3 px of one line, and the straight layout of such a map (arcs at the centres, metabolites at the yEd size).
cd_layout.pyCellDesigner: the boxes as it draws them (metabolite circles, multimers as dimers, room for a complex's name), the process glyph, connection points and edit points, the hidden ones included (the process glyph where the input has the process, a line into a large node beside its centre). It moves no node but for the room of a complex's name.
cd_tidy.pyFor CellDesigner (advanced): small moves that make lines meet straight (main lines up to 10 px, an end onto a larger node's centre line, a modifier up to 15 px onto its process glyph), listed under the map. The three other CellDesigner files go without.
newt_layout.pyNewt, only for the files for Newt (the SBGN-ML files keep the drawing of the input map): every process and gate in a compartment, each compartment as large as Newt's margin needs, neighbours too close for it moved apart, and an arc that leaves a node off centre bent just outside it, as Newt aims every arc at the node's centre.
style.pyyEd: standard node sizes and rescaling, for a map drawn at another scale.

Why biology and drawing apart

Most formats already keep them apart. CellDesigner has species and their aliases (one species can be drawn more than once). The SBML Layout package draws species and reactions with glyphs that refer to them by id. BioPAX has no drawing at all. v1's model had only the drawing: one node per alias, joined again by label when CellDesigner was written, so a species drawn twice came back as two species. Now the CellDesigner reader keeps each alias's species, and for yEd and SBGN-ML, which hold only a drawing, the biology is built from it, joining the nodes of one entity by their annotation (HGNC, UniProt, ChEBI), or by their label where a map has none. The biology alone is also what an export to BioPAX or to SBML without layout writes.

Maps only

Every route starts from a map. SBML with layout is written as Level 3 with the Layout and Render packages, drawn as the SBGN-ML file; it is not read on this page. SBML without layout and BioPAX are not written. Making a map from a file without a drawing (BioPAX, SBML without layout, a table) is the work of a layout tool, not of the converter.

Files edited in another program

A file saved by Newt, CellDesigner or yEd is read as any file of its format, whatever made it. The readers read only what the file says, so what the other program changed stays changed: there is no recovery of the original map on the way back. The files for Newt are made so that Newt has little to move.
